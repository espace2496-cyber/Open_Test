Plant設計 — 鉄骨設計 LE Action List

Lead Engineer 着任時に最初に実施すべきアクション一覧

1プロジェクト概要の把握
  • プロジェクト基本情報（プラント種別・規模・工期・予算）の確認 重要
  • 契約図書・仕様書（Job Specification）の入手と通読 文書
  • 適用基準・コード（AISC, AWS, 建築基準法 等）の確認 重要
  • クライアント Design Criteria / Design Basis の確認
  • 前任LEまたはプロジェクトマネージャーからの引継ぎ 打合せ
  • 過去の類似プロジェクト実績・Lessons Learned の収集
2設計条件の整理
  • 荷重条件の整理（自重・積載・風荷重・地震荷重・温度荷重・配管反力等） 重要
  • 地盤条件・基礎設計条件の確認（土質調査報告書の入手）
  • 耐火・防食要件の確認
  • 材料規格の選定（SS400, SM490, ASTM A36, A992 等）
  • 設計ソフトウェア・ツールの確認（STAAD.Pro, SAP2000, Tekla 等）
  • 接合部設計方針（ボルト接合 / 溶接接合）の基本方針策定
  • Deflection / Drift の許容値の確認
3体制構築とスケジュール策定
  • 鉄骨設計チームの編成・人員計画の作成 重要
  • Man-Hour 見積り・工数配分の策定
  • 設計スケジュール（マイルストーン）の作成 文書
  • 図面リスト（Drawing List）の作成
  • 設計計算書リスト（Calculation List）の作成
  • 他部門（配管・機器・電気・計装・土建）との Interface 確認 打合せ
  • 外注設計（Subcontract）範囲がある場合のスコープ明確化
4設計基盤の準備
  • 標準図・標準ディテール（Standard Detail）の選定・準備
  • CAD テンプレート・図枠の準備
  • 構造解析モデルの基本方針策定 重要
  • Pipe Rack / Equipment Support 等の主要構造物のタイプ分類
  • Key Plan / Plot Plan からの鉄骨構造物リストアップ
  • 設計計算書テンプレートの整備
  • 番号体系（マーク番号・図番ルール）の設定 文書
5品質管理・レビュー体制
  • 設計チェックリストの整備 チェック
  • 設計照査（Design Review）プロセスの確立 重要
  • Interdisciplinary Check（IDC）手順の確認
  • クライアント承認プロセス・提出フローの確認
  • NCR（不適合報告）/ 設計変更管理手順の確認
  • QMS（品質マネジメントシステム）要求事項の確認
6キックオフ・初期アクション
  • 鉄骨設計チーム内キックオフミーティングの実施 打合せ
  • 他部門との設計条件確認会議の設定 打合せ
  • 優先度の高い構造物（Long Lead Item 関連）の特定と着手 重要
  • MTO（Material Take Off）初版の計画
  • クライアントへの設計方針説明資料の準備 文書
  • リスク事項・未確定事項（TBD / TBC）の一覧作成 チェック

==============================================================================
  PDF → PowerPoint 変換マクロ 使い方ガイド
==============================================================================

■ 概要
  複数のPDFファイルを画像に変換し、1つのPowerPointにまとめます。
  各PDFはセクションで区切られ、セクション名にPDFファイル名が設定されます。
  外部ソフトのインストールは不要です（Windows標準APIを使用）。

■ 前提条件

  1. Windows 10 以降
     - Windows標準搭載のPDF描画API（Windows.Data.Pdf）を使用します
     - 追加ソフトのインストールは不要です

  2. Microsoft PowerPoint
     - PowerPointがインストールされている必要があります

■ セットアップ手順

  1. Excelを開く
     - 新規ブックまたは既存のブックを開きます

  2. VBAエディタを開く
     - Alt + F11 キーを押します

  3. 参照設定を追加
     - メニュー「ツール」→「参照設定」を開く
     - 以下にチェックを入れてOK:
       ☑ Microsoft PowerPoint XX.X Object Library

  4. モジュールをインポート
     - メニュー「ファイル」→「ファイルのインポート」
     - 「PdfToPpt.bas」ファイルを選択してインポート

     ※ または、モジュールを右クリック →「挿入」→「標準モジュール」で
       新しいモジュールを作成し、PdfToPpt.bas の内容を貼り付けてもOK

  5. マクロ有効ブックとして保存
     - 「名前を付けて保存」→ ファイルの種類を
       「Excel マクロ有効ブック (*.xlsm)」にして保存

■ 使い方

  1. Alt + F8 キーでマクロ一覧を開く
  2. 「ConvertPdfToPpt」を選択して「実行」
  3. ファイル選択ダイアログでPDFファイルを選ぶ（複数選択可）
     - Ctrlキーを押しながらクリックで複数ファイルを選択
     - Shiftキーを押しながらクリックで範囲選択
  4. 自動的に以下の処理が行われます:
     - 各PDFの全ページをPNG画像に変換（Windows標準API使用）
     - PowerPointを起動
     - PDFごとにセクションを作成（セクション名 = PDFファイル名）
     - 各ページの画像をスライドに貼り付け
     - PPTXファイルを保存
  5. 完了メッセージが表示されます

■ 出力ファイル名

  - PDF 1個の場合: 「（PDFファイル名）.pptx」
  - PDF 複数の場合: 「統合PDF.pptx」
  - 保存先は最初に選択したPDFと同じフォルダです

■ PowerPointのセクション構成

  例: 3つのPDFを選択した場合

  ┌─ セクション: 報告書A ─────────────┐
  │  スライド 1  (報告書A 1ページ目)      │
  │  スライド 2  (報告書A 2ページ目)      │
  │  スライド 3  (報告書A 3ページ目)      │
  ├─ セクション: 資料B ──────────────┤
  │  スライド 4  (資料B 1ページ目)        │
  │  スライド 5  (資料B 2ページ目)        │
  ├─ セクション: 参考C ──────────────┤
  │  スライド 6  (参考C 1ページ目)        │
  └──────────────────────────┘

■ カスタマイズ

  PdfToPpt.bas 先頭の設定値を変更できます:

  - DPI: 画像の解像度（デフォルト: 200）
    - 150: 軽量・やや粗い
    - 200: バランス良い（推奨）
    - 300: 高品質・ファイルサイズ大

■ トラブルシューティング

  Q: 「PDFから画像への変換に失敗しました」と表示される
  A: 以下を確認してください:
     - Windows 10 以降であること（Windows 7/8では動作しません）
     - PowerShellが使用可能であること
     - PDFファイルが破損していないこと
     - PDFファイルのパスに特殊文字が含まれていないこと

  Q: 一部のPDFだけ失敗する
  A: そのPDFはスキップされ、他のPDFは正常に処理されます。
     失敗したPDFが破損していないか確認してください。

  Q: 画像が粗い
  A: PdfToPpt.bas の DPI の値を 300 に変更してください。

  Q: 処理が遅い
  A: ページ数が多い場合やDPIが高い場合は時間がかかります。
     DPIを 150 に下げると高速化できます。

  Q: PowerPointが起動しない
  A: PowerPointがインストールされていることを確認してください。
     また、VBAの参照設定で PowerPoint Object Library が
     チェックされているか確認してください。

■ 技術的な仕組み

  1. VBAからPowerShellスクリプトを一時ファイルとして生成・実行
  2. PowerShell内でWindows.Data.Pdf（WinRT API）を使用し、
     PDFの各ページをPNG画像としてレンダリング
  3. VBAがPowerPoint COMオートメーションで画像をスライドに配置
  4. SectionProperties.AddBeforeSlide でPDFごとにセクションを作成
  5. 一時ファイル（画像・スクリプト）は自動的に削除

==============================================================================
  PDF → PowerPoint 変換マクロ 使い方ガイド
==============================================================================

■ 概要
  PDFファイルの全ページを画像に変換し、PowerPointの各スライドに
  1ページずつ貼り付けるExcel VBAマクロです。

■ 前提条件（必須）

  1. Ghostscript のインストール
     - 無料のPDF処理ツールです
     - ダウンロード: https://www.ghostscript.com/releases/gsdnld.html
     - 64bit版 Windows → 「Ghostscript AGPL Release」の64bit版を選択
     - インストーラの指示に従いインストールしてください

  2. Microsoft PowerPoint
     - PowerPointがインストールされている必要があります

■ セットアップ手順

  1. Excelを開く
     - 新規ブックまたは既存のブックを開きます

  2. VBAエディタを開く
     - Alt + F11 キーを押します

  3. 参照設定を追加
     - メニュー「ツール」→「参照設定」を開く
     - 以下にチェックを入れてOK:
       ☑ Microsoft PowerPoint XX.X Object Library
       ☑ Microsoft Scripting Runtime

  4. モジュールをインポート
     - メニュー「ファイル」→「ファイルのインポート」
     - 「PdfToPpt.bas」ファイルを選択してインポート

     ※ または、モジュールを右クリック →「挿入」→「標準モジュール」で
       新しいモジュールを作成し、PdfToPpt.bas の内容を貼り付けてもOK

  5. マクロ有効ブックとして保存
     - 「名前を付けて保存」→ ファイルの種類を
       「Excel マクロ有効ブック (*.xlsm)」にして保存

■ 使い方

  1. Alt + F8 キーでマクロ一覧を開く
  2. 「ConvertPdfToPpt」を選択して「実行」
  3. ファイル選択ダイアログでPDFファイルを選ぶ
  4. 自動的に以下の処理が行われます:
     - PDFの各ページをPNG画像に変換
     - PowerPointを起動
     - 各ページの画像をスライドに貼り付け
     - 元のPDFと同じフォルダにPPTXファイルを保存
  5. 完了メッセージが表示されます

■ カスタマイズ

  PdfToPpt.bas 先頭の設定値を変更できます:

  - GS_PATH: Ghostscriptのインストールパス
    （通常は自動検索されるため変更不要）

  - DPI: 画像の解像度（デフォルト: 200）
    - 150: 軽量・やや粗い
    - 200: バランス良い（推奨）
    - 300: 高品質・ファイルサイズ大

■ トラブルシューティング

  Q: 「PDFのページ数を取得できませんでした」と表示される
  A: Ghostscriptがインストールされていないか、パスが正しくありません。
     Ghostscriptをインストール後、再度実行してください。

  Q: 画像が粗い
  A: PdfToPpt.bas の DPI の値を 300 に変更してください。

  Q: 処理が遅い
  A: ページ数が多い場合やDPIが高い場合は時間がかかります。
     DPIを 150 に下げると高速化できます。

  Q: PowerPointが起動しない
  A: PowerPointがインストールされていることを確認してください。
     また、VBAの参照設定で PowerPoint Object Library が
     チェックされているか確認してください。
